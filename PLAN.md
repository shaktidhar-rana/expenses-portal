# PennyTrack Development Plan

## Current Scope

- Responsive browser-based personal expense tracker
- Dashboard for income, expenses, balance, budgets, and summaries
- Add, edit, delete, search, and filter transactions
- Custom categories with budget limits
- Reports, CSV import, and CSV export
- Browser-only persistence through `localStorage`

## Technology

- HTML5, CSS3, and vanilla JavaScript
- No build step or external runtime dependencies
- Vercel static deployment

## Future Enhancements

- User authentication and secure sessions
- Node.js/Express API
- PostgreSQL persistence
- Multi-device synchronization
